# UPI-Transaction-Dashboard-Using-Excel

### 📊 UPI Transaction Dashboard — LinkedIn Post

🚀 **Excited to share my latest Data Analytics project: UPI Transaction Dashboard!**

I created an interactive **UPI Transaction Dashboard in Excel** to analyze transaction trends, payment behavior, and overall transaction performance.

### 🔍 Key Insights Covered

* 💳 **5,02,887** total transactions
* 💰 **₹44.25 Cr** total transaction amount
* 🎁 **₹34.63 L** total cashback
* 📈 **91%** transaction success rate
* ⚠️ **17,089** suspected/fraudulent transactions
* 📱 Transaction analysis by **UPI App**
* 🏦 Transaction amount by **Bank**
* 🗺️ Transaction amount by **State**
* 🔄 Analysis by **Transaction Type & Status**
* 📅 Daily transaction amount trends

### 🛠️ Tools & Skills Used

**Microsoft Excel | PivotTables | PivotCharts | Slicers | Data Visualization | Data Cleaning | Dashboard Design | Business Analysis**

This project helped me strengthen my ability to transform raw transaction data into **interactive dashboards and actionable business insights**.

🎯 **Goal:** Make complex transaction data easy to understand and support better business decision-making.
